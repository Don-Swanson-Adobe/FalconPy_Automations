# Security

Thank you for helping keep this project and its users safe.

## Supported scope
These are sample projects for learning. They are not intended for direct production use.

## Reporting a vulnerability
Please report security issues privately using GitHub Security Advisories for this repository. If that is not possible, email the maintainer privately. Do not open a public issue that contains exploit details or secrets.

## What to include
* A clear description of the issue and impact
* Minimal steps to reproduce
* A suggested fix if you have one

We aim to acknowledge valid reports quickly and keep you updated until resolution.

## Secrets policy
Real credentials do not belong in this repository. Use environment variables or a cloud secrets manager in your own deployments.  
Do not log raw request bodies or tokens. Scrub sensitive fields in any logs you keep.

## Responsible disclosure
Please give us a reasonable chance to remediate before any public disclosure.
